# Dont name your baby is

This is a backend demo project for learning how to use Redux Toolkit (RTK) in a fullstack application.

## Project Structure

- `src/index.js`: Main Express server entry point
- `src/routes/`: API route definitions
- `src/controllers/`: Route handler logic
- `src/models/`: Data models (if needed)
- `src/middleware/`: Express middleware

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```

## RTK Integration

Redux Toolkit (RTK) is used on the frontend (React). This backend provides API endpoints for demo purposes. See the `frontend/` folder (to be created) for React + RTK usage.
